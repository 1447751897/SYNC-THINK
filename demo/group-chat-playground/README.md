# 群聊试验场（独立 Demo）

可玩的本地交互原型：公开 @、私人词卡、回合、投票、产物交接和中断接续。

**智能体是本地规则模拟，没有真实模型调用。** 不修改 SYNC-THINK 的页面、运行时、账号配置或真实工作区文件。

## 启动

在仓库根目录运行（Node.js 20 或以上，无新增依赖）：

    node demo/group-chat-playground/server.mjs

浏览器打开 http://127.0.0.1:4319 。端口占用时可使用 --port 4320。

## 建议体验顺序

1. 选择「参与游戏」，点击「开始一局」。右侧点击「查看我的词」。
2. 主持人依次点名；轮到你时输入描述，点击「提交本轮描述」。不要直接说出词本身。
3. 全员描述后，可公开 @阿岚 追问，或说出怀疑。点击「请求进入投票」后，在右侧正式投一票；聊天不自动计票。
4. 看主持人结算、下一轮或结局。每轮存活者再次描述；词卡不重新分配。
5. 开新局时可选择「观察主持视角」。该视角不参赛，有完整分配权限，不能在参赛途中直接切换。
6. 切换「任务协作」，填写总目标。观察直接咨询、三个可下载 Markdown 产物及交接。
7. 智能体执行时点「模拟成员中断」。协调员先检查，再续做同一动作。点「暂停」则自动接续也停止；刷新仍保留暂停与进度。
8. 左侧「本群描述」编辑下次使用的描述。「查看我的上下文」展示服务端按当前身份返回的数据。

## 信息边界

- 公共消息对群成员可见，@ 仅指定处理者。
- 词卡、私人笔记、未结算选票保存在服务端，不把完整分配表下发给玩家客户端。
- 模拟玩家与 HTTP 客户端共用上下文投影；模拟投票只使用自己的词及公开描述，不读取真实卧底身份。
- 主持人可以读取分配，但不默认取得玩家私人笔记。投票收齐才公开结果；结局才揭晓词卡。
- 当前浏览器的随机 HttpOnly / SameSite cookie 绑定一个 Demo 活动，不接受请求参数伪装其他成员。
- 服务只监听本机回环地址，写操作检查 Origin；不是完整的多用户账号系统。
- 状态保存到本目录 .state/playground.json，包含模拟秘密。设备拥有者可主动检查底层文件；这里保证正常玩法视角隔离，不保证对本机管理员保密。
- 同一浏览器刷新、服务重启保留活动。其他浏览器 / 无痕窗口各自建立活动。

## 模拟范围

- 谁是卧底：五位玩家、一名卧底、无白板；最多八轮。平票候选人补充描述并重投一次，再平票则无人出局。卧底出局平民胜；剩两人且卧底仍在则卧底胜。
- 描述来自按个人词语选取的本地线索，投票使用公开线索匹配；不代表真实语言模型的聊天、推理能力。
- 编辑群描述用于验证上下文随群保存，不自动将任意自然语言编译成新规则。具体玩法由该 Demo 固定状态机执行。
- 工作产物是真实可下载的演示文档；没有执行实际仓库研究、代码修复、外部发送或模型生成。
- 中断按钮模拟故障；回合和投票使用独立提交记录，暂停优先于自动续跑。每个同一动作的自动恢复预算为两次，耗尽后需手动继续。
- 暂未接入真正模型、狼人杀、玩家之间的私聊或多设备联机。
