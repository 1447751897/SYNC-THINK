# SYNC-THINK 全系统交互 Demo

双击 `index.html` 即可在本地浏览器打开，也可用静态服务器预览。图标脚本已内嵌；字体在线时使用 Geist，离线时使用系统字体。刷新页面后，本地演示状态保留在浏览器存储中。

推荐试用：新对话 → 选择模型与思考强度 → 输入 `/review 修复定时任务模型绑定并检查对话跳转` → 发送 → 播放或逐步查看执行流 → 展开 `terminal.exec` 等工具调用 → 查看答复、引用、审阅和终端。切换智能体/小队可体验其他输出，`/browser` 可体验浏览器执行与审批。设置页从左下角进入，包含分类、权限、思考、默认模型与外观。

这是仅在页面内运行的交互样例。对话、命令、浏览器和任务执行是示例数据，不会调用真实模型、终端或网站。
