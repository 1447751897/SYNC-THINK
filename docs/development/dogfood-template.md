# M1 Dogfood 日记模板（至少 1 个真实使用日）

> 设计：M1 退出前需要「你自己用它做真实规划对话 ≥1 天」。  
> 本文件是模板；真实日记可复制为 `docs/development/dogfood/YYYY-MM-DD.md`。  
> **至少完成 1 天有效记录后，才可关闭 M1。**

## 使用方式
1. 每个真实使用日新建一份日记（或复制本模板改日期）
2. 至少完成：选 2 个 Provider / 3 个模型切换、看一次 Manifest、折叠/展开 trace、重启后确认对话还在
3. 若用了 MCP：记录「刷新工具目录 / 审批 / 真调用」是否符合预期
4. 把严重问题记到「阻塞」；把不爽记到「摩擦」
