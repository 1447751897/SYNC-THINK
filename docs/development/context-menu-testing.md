# Sync-Think 右键菜单测试清单

更新日期：2026-09-27。

这轮覆盖输入框、消息、选中文字、链接、代码块、执行记录、文件 Diff 和侧栏对话。菜单沿用应用主题，深浅色均可用；原有图片、图表等专用右键菜单保留。

## 准备

打开本地 Sync-Think 开发版，新建「右键测试」对话。在输入框保留「已有草稿」，测试引用时观察这段内容是否仍在。

让模型生成一条包含标题、加粗、网页链接和 TypeScript 代码块的回答。命令、失败输出和 Diff 也可以使用已有历史记录；打开菜单和复制本身不会调用模型。

## 1. 输入框

键入「alpha beta」，选中 alpha 后右键。

- **复制**：粘贴到另一文本框，应得到 alpha，原文保留。
- **剪切**：应移除 alpha，剪贴板得到 alpha。
- **粘贴**：将剪贴板内容插入当前光标位置，或替换当前选区。
- **全选**：选中当前输入框内容，不选中整个页面。
- **撤销**：撤销上一次输入或粘贴；聊天输入框使用自己的编辑历史。
- **重做**：恢复刚撤销的内容。聊天输入框没有对应历史时，撤销或重做禁用。

在设置搜索框等普通输入框重复测试。只读文本框不显示剪切和粘贴；密码框的复制、剪切禁用。

## 2. 消息和选中文字

右键点击消息正文中的普通文字或留白。点击代码块、链接或已选中的文字时，会展示对应对象的菜单。

- **复制整条消息**：粘贴后得到可读纯文本，去掉加粗、标题、链接等 Markdown 标记，保留代码正文。
- **复制 Markdown 原文**：保留 Markdown 标记和代码围栏；长消息应完整复制。
- **引用这条消息**：在当前输入框末尾追加引用，保留「已有草稿」，光标进入输入框；不会自动发送。
- **复制选中文字**：选中同一条消息中的一句话，再右键，应仅复制该句。
- **引用选中文字**：同样选中一句话再右键，输入框应只追加所选文字的引用。
- **重新生成回答**：在已结束的助手消息上选择，进入原有重新生成流程。这项会发起模型请求。
- **继续回答**：对中断、取消或失败后可续答的助手消息显示，选择后进入原有继续流程。这项会发起模型请求。

正在生成时，重新生成和继续回答禁用。用户消息不显示这两项。在另一条消息上右键，不应误引用此前选中的文字。

## 3. 链接和代码块

右键回答中的网页链接：

- **复制链接地址**：粘贴后得到完整 URL。
- **打开链接**：沿用原有链接打开方式，与左键点击一致。

右键回答中的代码块：

- **复制代码**：得到原始代码，无行号、语言标签或展示截断提示；很长的代码也应完整复制。
- **引用代码到输入框**：代码追加到当前草稿，不发送。
- 选中代码的一部分后右键，可仅复制或引用所选文字。
- 代码仍在生成时，复制项标注为「复制当前代码」。

## 4. 命令执行和工具记录

在执行过程中的命令行或展开详情内右键：

- **复制命令**：只复制实际命令正文，不包含 PowerShell 可执行文件路径、cwd、processId 等包装信息。
- **复制输出**：复制完整已保存输出，不只复制屏幕预览。执行中显示「复制当前输出」；只有截断的实时日志时显示「复制当前日志片段」。
- **引用错误并提问**：在失败的执行记录上显示，将命令和错误追加到草稿，保留已有输入，不自动发送或重跑。
- **展开详情 / 收起详情**：切换现有工具详情区域。
- **复制文件路径 / 打开对应文件**：工具记录含明确文件路径，且存在原有打开入口时显示；打开后进入现有文件面板。

复制和引用不会执行命令。在活动执行区打开菜单时，会暂停自动跟随，避免记录在操作时移动。

缺少失败样例时，可在测试对话中让模型执行一个明确以非零状态结束的命令，例如：

~~~text
node -e "console.error('RIGHT_CLICK_TEST'); process.exit(1)"
~~~

## 5. 文件 Diff

展开一条真实文件修改记录，对 Diff 区域右键：

- **复制 Diff**：粘贴后包含 hunk 和加减行标记。
- **复制修改后内容**：在持有完整新文本的 Diff 上显示，只复制新文件内容，不带加减号。仅有补丁片段的记录不伪造整份文件内容。
- **复制文件路径**：得到对应路径。
- **打开对应文件**：通过现有回调打开右侧文件面板。
- 选中某几行后右键，可以复制或引用所选文字。

可以用一个临时测试文件，先写入「const count = 1;」，再让模型改成「const count = 5;」，得到易于核对的 Diff。

## 6. 侧栏对话

在侧栏「最近对话」的测试对话上右键：

- **重命名对话**：弹出原有重命名入口，改名后列表同步更新。
- **复制对话**：调用原有复制流程，原对话保留。
- **复制对话链接**：粘贴后得到对应对话的链接。
- **置顶对话 / 取消置顶**：菜单文字随状态变化；排序沿用原有规则。
- **移动到分组**：先建一个测试分组，再在子菜单选择它；当前分组带勾。
- **移出分组**：对分组中的对话打开子菜单，选择后回到未分组区域。
- **归档对话 / 取消归档**：归档后移入归档区；在归档列表上右键可恢复。
- **多选**：进入原有多选模式；菜单变为「选择对话 / 取消选择」。
- **删除对话**：进入原有删除确认流程。先选择取消，确认对话仍在，再用测试对话验证删除。

右键复用原来的「…」菜单回调，仍可继续使用「…」入口。

## 7. 位置、键盘和主题

- 在窗口边缘附近右键，菜单应翻转或移动到可见区域；子菜单也应保持可见。
- Tab 聚焦输入框、消息或对话后按 Shift+F10，可打开同一个菜单。
- 按 Escape 关闭后焦点回到原对象；输入框选区应保留。
- 点击菜单外关闭，不应执行操作。
- 切换深色和浅色主题，检查文字、图标、禁用状态与删除项颜色。
- 系统启用减少动画时，不播放入场动画。
