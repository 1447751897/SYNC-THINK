# ADR 0002：协作聊天与可验收工作流分离

- 状态：已接受
- 日期：2026-09-29
- 范围：协作聊天、运行时调度、任务详情

## 决定

普通回复（reply）不等于可执行任务（task）。协调人的回复轮可以在用户要求执行时调用结构化工作流工具；问候和讨论不启动流程。工作流把团队成员、串并行策略与依赖冻结成调度节点，任务启动前等待前置交付。文本 @成员不产生派发。

每次成员执行接收截至该轮消息边界的群聊历史，以及前置节点已提交的产物与版本。产物超出上下文预算时显式失败，不静默截断交接。

新工作流节点必须声明 document 或 file 交付合同并成功调用产物提交工具。文档正文由宿主持久化在当前 attempt 中，不是授予智能体工作区写权限；文件交付检查工作区路径、实际文件、大小与本轮内容变化。模型正常结束不再自动代表产物交付成功。这是结构性验收，不声称替代语义质量审查。

保留旧任务和历史的兼容读取；重试创建新的 attempt，旧产物不冒充本轮交付。依赖失败的后续节点停止，并在前置任务重试后恢复。模型对话调用智能体仍保留原对话归属。

## 与 ADR 0001 的关系

保持最严格权限：工作区文件写入需智能体 inherit 且会话允许写入。调度本团队以及向会话提交文档是范围受控的宿主动作，与动态子智能体和工作区写工具分离；不扩大只读文件工具白名单。

## 展示与部署

智能体主聊天只显示执行状态与最终交付。公开过程说明和工具输入输出进入任务详情的真实运行时间线；内部推理正文不展示。详情支持阶段依赖与可预览/下载的版本化产物。

协作响应携带 executionVersion=2。新版界面连接旧守护进程时明确提示版本不匹配，避免仅刷新界面产生已升级的错觉。
