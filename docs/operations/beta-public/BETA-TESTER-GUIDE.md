# SYNC-THINK 公开 Beta 测试说明

版本：`0.1.0-beta.1`  
平台：Windows 11 x64  
签名：无（SmartScreen 会提醒）  
自动更新：关闭，请从下载页手动取新包

## 1. 安装前

1. 只要 Windows 11 x64。不要在 Windows 10 / ARM 上当正式环境。
2. 下载 `SYNC-THINK-Setup-0.1.0-beta.1-x64.exe`。
3. 用 PowerShell 核对哈希，必须与下载页一致：

```powershell
Get-FileHash .\SYNC-THINK-Setup-0.1.0-beta.1-x64.exe -Algorithm SHA256
```

4. 若哈希不一致，删除文件，不要安装。

## 2. SmartScreen

未签名包常见提示是「Windows 已保护你的 PC」。

1. 点「更多信息」。
2. 点「仍要运行」。
3. 按安装向导完成本机 per-user 安装。不要改到别人的用户目录。

## 3. 第一次打开

1. 开头页和对话空态一样，点输入框打开一个本地工作区。任务和文件只应落在这个目录里。
2. 若还没有模型，页面上方会出现「添加 API 密钥」。密钥只保存在本机安全存储。
3. 需要 Codex / Claude Code 时，在「设置 → 关于」里安装到应用私有目录。不要装 Pi：本轮执行未接通。
4. 不要设置 `SYNC_THINK_DEV_NO_TOKEN` 或固定 `SYNC_THINK_INSTALL_ID`。安装包会自己生成安装身份。

## 4. 你在测什么

- 对话、模型切换、工具审批、本机浏览器和工作区文件。
- 首次配置密钥后能否真正发出一轮请求。
- 崩溃或卡住时，「设置 → 数据」导出的诊断是否够用。

## 5. 已知限制

- 没有自动更新。有新版本时回到下载页再装。
- 关于页的「检查更新」在本轮是关闭的，这是预期。
- Pi 内核不可用。
- 账号、钱包、组织、云同步不在 Beta 范围。
- 这是 Beta：可能丢状态、可能要手动重装。请先在不重要的文件夹里试。

## 6. 反馈

导出脱敏诊断，附上：

- 版本 `0.1.0-beta.1`
- 重现步骤
- 是否改过 SmartScreen / 杀毒软件
- 不要发送 API 密钥、数据库文件或完整 userData
