装上之后

  1. 打开一个本地工作区文件夹。
  2. 到「设置 → 模型」添加你自己的 API 密钥或网关，不要使用别人的密钥。
  3. 可选：在关于页安装私有 Codex / Claude Code。Pi 本轮不可用。
  4. 本轮没有自动更新。有新包时回到这个页面重新下载。

数据与范围

  • 数据只写本机 userData 与本地数据库，卸载默认保留。
  • 包内不含开发者密钥，也不含别人的对话记录。
  • 需要排障时，用「设置 → 数据」导出脱敏诊断，不要发送原始数据库。
