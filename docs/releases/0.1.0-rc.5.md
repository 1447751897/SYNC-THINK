# SYNC-THINK v0.1.0-rc.5 — 应用内更新与自动升级

Windows 11 x64 Alpha 预发布版。本版**首次接入自动更新通道**：安装后无需配置环境变量即可在设置页检查新版本、查看更新日志、下载并一键重启安装。

- 大小：240,349,168 字节（约 240.3 MB / 229.2 MiB）。
- SHA-256：`d963f6f7f7be45233505bb144b157a73eebadc36675a77e9e714abaa434a0d1c`。
- 校验命令：`Get-FileHash .\SYNC-THINK-Setup-0.1.0-rc.5-x64.exe -Algorithm SHA256`。
- 校验不一致时不要运行，请重新下载。

## 新增：应用内更新

- **更新日志就在应用里**：设置 → 关于的更新面板直接渲染本版本的更新说明，不再跳转到 GitHub 网页。
- **更新源随安装包内置**：feed 地址在构建期固化进 `resources/update-feed.json`，安装后开箱即是“已配置更新通道”状态；环境变量仍可覆盖，方便内测与回归。
- **应用内下载并安装**：检查更新 → 下载（显示进度与字节数，支持差分 blockmap）→「重启并安装」，静默退出后自动完成升级并重新拉起应用。
- **失败可回滚**：升级失败由独立 watchdog 协调回滚到旧版本，脱敏的恢复证据落在 `<userData>/diagnostics/desktop-updater-recovery.json`。
- **更新源防护**：客户端只接受 HTTPS（仅 `localhost/127.0.0.1` 放行 HTTP），拒绝带用户名/密码/查询串/锚点的 feed 地址。

## 修复

- 修复 Windows 安装包无法产出的构建配置问题：`mac` 段里的 `arch` 不是 electron-builder 26 的合法属性（架构应由 CLI 指定），已移除；`gatekeeperAssess` 在 26 中仍合法，保留原有取值。

## 升级须知（重要）

- **从 rc.4 及更早版本升级到 rc.5，需要手动安装一次。** 旧版本体内没有内置更新源，无法自动发现 rc.5；手动装上 rc.5 之后，后续版本即可自动更新。
- 安装包**仍未签名**（`unsigned-fixture`）。首次运行可能出现 Windows 发布者/信誉提示，无需导入根证书。自动更新的完整性依赖 feed 元数据中的 SHA-512 校验，请在可信网络下进行。
- 测试重装时可先退出程序并用系统卸载入口卸载旧版本，不要选择删除用户数据；安装目录与用户数据目录是分开的。

## 已知限制

- 仍为 Alpha：干净 Windows 机器、磁盘满、安装中断及完整模型使用流程需要继续验证。
- 差分更新只在上一版本安装包仍在更新缓存中时生效；否则走整包下载。
- 反馈请附版本号、Windows 版本、具体错误和脱敏诊断日志；请勿上传 API 密钥或聊天数据库。
