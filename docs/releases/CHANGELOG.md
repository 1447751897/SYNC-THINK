# SYNC-THINK 更新日志

本文件是**面向用户的更新日志唯一事实来源**。下列三处全部从这里派生，不允许各写一份：

- 客户端「设置 → 关于 → 查看更新日志」弹窗（展示当前安装版本的日志）
- 线上更新源的 `releaseNotes`（有新版本时展示该版本的日志）
- `docs/releases/<版本>.md` 发布说明中的用户向摘要

## 格式约定（机器解析，勿改动标记）

- `## <版本号> — <YYYY-MM-DD>` 开始一个版本段落，日期用 ISO 8601（例：`2026-09-14`）。
- `> ` 开头为版本摘要，可选，紧跟在版本标题之后。
- `### <分段名>` 开始一个分段，常用分段名：`新功能`、`优化`、`修复`、`升级须知`、`已知限制`。
- `1. ` 或 `- ` 开头为一个条目。
- `---` 用于分隔版本段落，可选。
- 版本段落按**从新到旧**排列；客户端只需要当前版本那一段，解析器按版本号精确切片。

## 0.1.0-rc.7 — 2026-09-15

> Windows 11 x64 Alpha 预发布版。本版重做了「更新日志」弹窗：修好了它铺满整屏的显示问题，并让它能回看全部历史版本。

### 新功能

1. 回看全部历史版本 — 「查看更新日志」不再只显示当前这一版，而是按从新到旧列出全部版本的说明。正在运行的版本标「当前版本」；发现新版本时那一版置顶标「待更新」，升级前后都能翻到任何一版。

### 优化

1. 更新日志更好读 — 版本摘要单独成块，分段标题与条目列表拉开层级，条目折行后与正文列对齐（长条目不再折回左边缘挤成一坨），版本之间用分隔线断开。
2. 弹窗补齐标题栏与页脚 — 标题带上图标与版本标记，页脚补上右对齐的「知道了」，尺寸与入场动画对齐产品内其它弹窗。

### 修复

1. 修复「查看更新日志」铺满整屏：弹窗遮罩原先用的是一个不透明的表面色，点开后设置页被整片盖住、只剩中间一张卡片。现在改为跟随主题的半透明浮层，背后页面仍然可见。

## 0.1.0-rc.6 — 2026-09-14

> Windows 11 x64 Alpha 预发布版。本版把「有新版本」直接摆到用户面前：更新日志随时可以点开看，设置入口直接显示要升到哪个版本。

### 新功能

1. 应用内查看更新日志 — 设置 → 关于新增「查看更新日志」按钮，点击即弹出完整说明，支持 Esc 关闭并把焦点还给按钮，全程不会打开浏览器。
2. 新版本一眼可见 — 侧边栏底部的设置入口在发现新版本后直接显示目标版本号；关于页的更新按钮也从「下载更新」变为「更新到 vX.Y.Z」，点之前就知道要升到哪一版。
3. 下载与更新同源 — 新用户从官网下载到的安装包，与老用户自动更新拿到的安装包，现在是同一次发布产出的同一份文件，不会再出现「下载到旧版、自动更新到新版」。

### 修复

1. 修复升级前签名校验的内部调用缺陷：命令参数绑定失败导致校验必然报错，并因此跳过健康标记。现在能取到真实的签名状态，为启用代码签名后的回滚保护铺路。

### 已知限制

1. 安装包仍未签名，因此升级前的回滚保护当前不会生效：未签名包无法通过签名校验，当前版本不会被登记为可回滚点，升级失败时不会自动退回旧版本。启用代码签名证书后该保护才会真正工作；升级包的完整性仍由更新元数据中的 SHA-512 校验保障。
2. 从 rc.4 及更早版本升级到本版，仍需手动安装一次：旧版本体内没有内置更新源，无法自动发现新版本。

## 0.1.0-rc.5 — 2026-09-14

> Windows 11 x64 Alpha 预发布版。本版首次接入自动更新通道：安装后无需配置环境变量，即可在设置页检查新版本、查看更新日志、下载并一键重启安装。

### 新功能

1. 更新日志就在应用里 — 设置 → 关于的更新面板直接显示本版本的更新说明，不再跳转到 GitHub 网页。
2. 更新源随安装包内置 — 更新源地址在构建期固化进安装包，装完开箱即是「已配置更新通道」状态；环境变量仍可覆盖，方便内测与回归。
3. 应用内下载并安装 — 检查更新 → 下载（显示进度与字节数，支持差分下载）→「重启并安装」，静默退出后自动完成升级并重新拉起应用。
4. 升级失败可回滚 — 升级失败由独立 watchdog 协调回滚到旧版本，脱敏的恢复证据落在本机诊断目录。
5. 更新源防护 — 客户端只接受 HTTPS 更新源（仅本机回环地址放行 HTTP），拒绝带用户名、密码、查询串或锚点的地址。

### 修复

1. 修复 Windows 安装包无法产出的构建配置问题：`mac` 段里的 `arch` 不是 electron-builder 26 的合法属性（架构应由命令行指定），已移除。

### 升级须知

1. 从 rc.4 及更早版本升级到 rc.5，需要手动安装一次：旧版本体内没有内置更新源，无法自动发现 rc.5；手动装上 rc.5 之后，后续版本即可自动更新。
2. 安装包仍未签名，首次运行可能出现 Windows 发布者或信誉提示，无需导入根证书。自动更新的完整性依赖更新元数据中的 SHA-512 校验，请在可信网络下进行。
3. 测试重装时请先退出程序并使用系统卸载入口卸载旧版本，不要选择删除用户数据；安装目录与用户数据目录是分开的。

### 已知限制

1. 仍为 Alpha：干净 Windows 机器、磁盘满、安装中断及完整模型使用流程需要继续验证。
2. 差分更新只在上一版本安装包仍留在更新缓存中时生效，否则走整包下载。

## 0.1.0-rc.4 — 2026-09-07

> Windows 11 x64 Alpha 预发布版。本版为未签名安装包，用于手动下载安装测试，不是自动更新推送。

### 优化

1. 直接解压到安装目录，省去整份展开文件在临时目录中转后的重复复制；约 777 MB 的展开临时文件和一次对应写入不再需要。
2. 安装耗时明显缩短：同机单轮实测全新安装由 302 秒降至 103 秒，覆盖安装由 402 秒降至 181 秒，不保证每台电脑取得同样结果。

### 修复

1. 修复安装接近结束时误报「安装已中止」：回滚安装包保存成功后，安装器检查了错误的结果寄存器。
2. 解压失败时明确报错；损坏包、目标路径不可写和文件占用均有真实回归测试。

### 已知限制

1. 自动更新未开放，本版请手动下载。
2. 仍为 Alpha：解压失败可能留下部分程序文件，解决报错原因后重新运行安装器即可。

## 0.1.0-rc.2 — 2026-09-07

> Windows 11 x64 Alpha 第二个内测包，本次为无签名包（rc.1 的自签名证书暂未启用，后续补签）。

### 新功能

1. 执行过程体验：失败命令自动收起、排队不打断，步骤与命令结果一次展示。
2. 右侧工作台：同一轮可打开多个网页且不覆盖已有页。
3. 工作区文件、审阅与新建文档一次展示，去掉分页。
4. MCP 卡片显示品牌图标与可调用状态；Skill 常驻上下文按 description 统计。
5. 内嵌浏览器支持滚轮缩放与点击识别文本定位器。

### 优化

1. 开源准备：仓库改为 MIT 许可，`main` 成为主线。
2. 开头页改为对话空态；公开分发去掉 Pi，关于页支持手动下载。
3. 安装包瘦身：解包体积由 858 MB 降至 749 MB，安装器由 224 MB 降至 195 MB（剪除 .d.ts、sourcemap、原生源码与非 zh-CN/en-US 语言包，移除零引用依赖）。

### 已知限制

1. 无自动更新，新版本需回发布页手动下载。
2. 无签名，SmartScreen 会提示。

## 0.1.0-rc.1 — 2026-09-01

> Windows 11 x64 Alpha 首个内测构建，使用自签名代码签名证书（含 DigiCert RFC 3161 时间戳）。

### 新功能

1. 首个可安装的 Windows 内测版本，本地优先的多模型 Agent 桌面工作区。
