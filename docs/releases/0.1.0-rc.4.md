# SYNC-THINK v0.1.0-rc.4 — 安装修复与性能优化

Windows 11 x64 Alpha 预发布版。本版本为**未签名安装包**，用于手动下载安装测试，不是自动更新推送。

## 下载与安装

下载本 Release 的 `SYNC-THINK-Setup-0.1.0-rc.4-x64.exe`，不需要下载源码压缩包、blockmap 或清单文件。

- 大小：204,511,759 字节（约 204.5 MB / 195.0 MiB）。
- SHA-256：`8957508d48ec0442fef4e9a6daf2a2244137777b28e3a8c65b6aa4c973c63440`。
- 校验命令：`Get-FileHash .\SYNC-THINK-Setup-0.1.0-rc.4-x64.exe -Algorithm SHA256`。
- 校验不一致时不要运行，请重新下载。未签名包可能触发 Windows 发布者/信誉提示；无需导入根证书。
- 测试重装时，可先退出程序并使用系统卸载入口卸载旧版本；不要选择删除用户数据。安装目录与用户数据目录是分开的。

## 修复与优化

- 修复安装接近结束时误报“安装已中止”：回滚安装包保存成功后，NSIS 检查了错误的结果寄存器。
- 直接解压到安装目录，省去整份展开文件在临时目录中转后的重复复制；约 777 MB 的展开临时文件和一次对应写入不再需要。
- 解压失败明确报错；损坏包、目标路径不可写和文件占用均有真实 NSIS 回归测试。
- 保留完整应用内容、差分包、回滚归档及标准卸载器构建流程，不把安装等待转移到首次启动。

## 已知限制与反馈

- 安装包仍约 204.5 MB，本轮主要优化安装耗时及临时磁盘占用，并未删减内核或功能。
