## 应用内升级

1. 在 SYNC-THINK 打开「设置 → 关于 → 检查更新」。
2. 发现 `0.1.0-rc.8` 后点击「更新到 v0.1.0-rc.8」，由应用下载更新。
3. 下载完成后确认「重启并安装」。正常升级不需要到网页手动下载安装包。
