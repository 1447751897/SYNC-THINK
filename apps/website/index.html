常见问题

开始之前，
你可能想知道。

桌面端一定要登录才能使用吗？

本地工作台可独立使用。官网账号用于云端身份，桌面端账号绑定和跨设备同步将在后续接入。

我的任务和 API 密钥保存在哪里？

桌面端对话与任务保存在本机，模型请求会发送到你配置的服务商。模型密钥使用本机安全存储，云端账号不会自动上传这些密钥。

现在可以在云端运行 Agent 吗？

当前版本仍由 Windows 桌面端执行任务。云端首版包含官网与账号服务；设备连接、任务同步和远程执行属于后续阶段。

支持哪些模型和工具？

支持 OpenAI-compatible 与 Anthropic-compatible 服务，可使用已配置的 Skill、MCP，以及 Claude Code 与 Codex 内核。具体可用范围以当前版本和本机配置为准。

如何下载和更新？

前往 GitHub Releases 下载 Windows 安装包。目前为 Alpha 阶段，安装包未签名，更新通过手动下载完成。安装前请核对版本说明与文件校验值。
