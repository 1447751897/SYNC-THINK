# Third-party Provider logos

These SVG brand marks identify the corresponding account integrations. They are packaged locally; rendering never requests a logo from an external domain.

- SVGL assets are vendored from the pinned commit recorded in `sources.json`, with the upstream MIT license in `LICENSE.svgl.txt`.
- Gitee, Jira and Google Docs are from the pinned Simple Icons commit recorded in `sources.json`, with the upstream CC0 text in `LICENSE.simple-icons.md`. Their path data is unchanged; the upstream brand color is applied as the root fill.
- Brand names and marks remain the property of their respective owners. Included resource licenses do not imply affiliation or endorsement.

To update, use the per-asset source record, verify the new mark, and retain source/license attribution. Do not replace these with invented or letter-only brand marks.
